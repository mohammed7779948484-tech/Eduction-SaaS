   622→   622→8. Professional Iterative Review Loop
   623→   623→
   624→   624→Do not perform the task as a single implementation pass.
   625→   625→
   626→   626→Use a structured quality loop for every major milestone.
   627→   627→
   628→   628→Each milestone must follow this process:
   629→   629→
   630→   630→Step A: Source Alignment
   631→   631→
   632→   632→Before implementing the milestone:
   633→   633→
   634→   634→* Re-read the relevant client-source sections.
   635→   635→* Re-read relevant Phase 1 sections.
   636→   636→* Re-inspect the relevant reference image area.
   637→   637→* Re-read the applicable project documentation.
   638→   638→* Record the milestone requirements.
   639→   639→
   640→   640→Step B: Primary Implementation
   641→   641→
   642→   642→The primary agent performs the implementation.
   643→   643→
   644→   644→Subagents do not lead the initial implementation.
   645→   645→
   646→   646→Step C: Primary Self-Review
   647→   647→
   648→   648→The primary agent must review its own work before involving subagents.
   649→   649→
   650→   650→Check:
   651→   651→
   652→   652→* Source alignment.
   653→   653→* Technical correctness.
   654→   654→* Reuse.
   655→   655→* RTL.
   656→   656→* Responsive behavior.
   657→   657→* Accessibility.
   658→   658→* Visual quality.
   659→   659→* Documentation alignment.
   660→   660→* Missing states.
   661→   661→* Broken assumptions.
   662→   662→
   663→   663→Fix obvious issues before requesting specialist reviews.
   664→   664→
   665→   665→Step D: Specialist Reviews
   666→   666→
   667→   667→Assign the milestone to the relevant subagents.
   668→   668→
   669→   669→Each reviewer must inspect the actual implementation and provide evidence-based findings.
   670→   670→
   671→   671→Do not ask every subagent to review every milestone.
   672→   672→
   673→   673→Use only the relevant specialists.
   674→   674→
   675→   675→Step E: Findings Consolidation
   676→   676→
   677→   677→The primary agent consolidates findings into one ordered correction list.
   678→   678→
   679→   679→Resolve duplicated or conflicting findings.
   680→   680→
   681→   681→Prioritize in this order:
   682→   682→
   683→   683→1. Blockers.
   684→   684→2. Critical issues.
   685→   685→3. Major issues.
   686→   686→4. Minor issues.
   687→   687→5. Suggestions.
   688→   688→
   689→   689→Step F: Correction
   690→   690→
   691→   691→The primary agent applies the accepted corrections.
   692→   692→
   693→   693→Do not allow uncontrolled parallel edits.
   694→   694→
   695→   695→Step G: Reverification
   696→   696→
   697→   697→After corrections:
   698→   698→
   699→   699→* Rerun technical checks.
   700→   700→* Rerun relevant visual checks.
   701→   701→* Reopen the affected source files.
   702→   702→* Confirm the correction did not introduce regressions.
   703→   703→* Update documentation.
   704→   704→
   705→   705→Step H: Repeat
   706→   706→
   707→   707→Repeat the review cycle until the milestone satisfies its completion gate.
   708→   708→
   709→   709→A milestone is not complete while it contains:
   710→   710→
   711→   711→* Any BLOCKER.
   712→   712→* Any CRITICAL.
   713→   713→* Any unresolved MAJOR.
   714→   714→* A conflict between implementation and authoritative source files.
   715→   715→* Broken lint, type, build, or runtime checks.
   716→   716→* A serious RTL or accessibility defect.
   717→   717→* A major visual defect at a required viewport.
   718→   718→* Documentation that contradicts the implementation.
   719→   719→
   720→   720→Perform at least two meaningful review passes for:
   721→   721→
   722→   722→* Source extraction and requirements.
   723→   723→* Dependency cleanup.
   724→   724→* DESIGN.md and tokens.
   725→   725→* /design-system.
   726→   726→* Homepage implementation.
   727→   727→* Final repository consistency.
   728→   728→
   729→   729→Do not loop indefinitely over subjective preferences.
   730→   730→
   731→   731→After the required quality gate is met:
   732→   732→
   733→   733→* Document accepted minor issues.
   734→   734→* Document deferred suggestions.
   735→   735→* Proceed to the next milestone.
   736→   736→
