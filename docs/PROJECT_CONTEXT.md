# Project Context

## Client
برنامج الحساب الذهني (Mental Arithmetic Program) — a Soroban-based mental-arithmetic education program for children aged 7–12, operating in Yemen across three learning channels: in-center, partner-schools, and online (future).

## Engagement
A consulting/dev team is delivering a 3-phase digital roadmap:
1. **Phase 1 (this prototype):** public institutional marketing site — build trust, collect registrations + trial-lesson bookings, prepare a scalable base.
2. Phase 2: e-learning platform with secure online payment.
3. Phase 3: web app.

This repository = a **high-fidelity interactive frontend prototype of the Phase 1 public site's homepage + design system**, for client presentation and contract approval.

## Goals of the prototype
- Let the client **understand the proposed website**.
- **Review the visual identity** extended from their logo.
- **Experience the homepage direction**.
- **Approve the visual approach** and gain confidence → commercial contract.

## Non-goals (production — out of scope)
Database, auth, CMS, real APIs, payments, real AI assistant, real form submission, remaining pages. See `AGENTS.md` §2.
