# برنامج الحساب الذهني — Mental Arithmetic Program (Prototype)

High-fidelity **frontend prototype** of the public institutional website for the Mental Arithmetic Program (Soroban, Yemen). Built for a **client presentation** to approve the visual identity and homepage direction.

> This is a **prototype**, not production. Static, frontend-only, Arabic-first, RTL. No database, auth, backend, or CMS.

## What's implemented
- Design system: `DESIGN.md` + brand tokens (`src/styles/tokens.css`) + `/design-system` reference page.
- Shared layout: header, footer, containers, section headings.
- **Homepage only** (`/`).

## Stack
Next.js 16 · React 19 · TypeScript 5 · Tailwind CSS v4 · shadcn/ui (New York) · Framer Motion · GSAP (hero only) · Bun.

## Getting started
```bash
bun install
bun run dev      # http://localhost:3000 (logs → dev.log)
bun run lint
```
